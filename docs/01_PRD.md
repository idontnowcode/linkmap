# 01 — PRD (Product Requirement Document)

> LinkMap · v1 (MVP) · 2026-06-22

## 1. 프로젝트명
**LinkMap** — 관계형 북마크 그래프 매니저 (데스크톱)

## 2. 제품 비전
사용자가 저장한 링크(URL)를 단순한 폴더형 북마크 리스트가 아니라 **관계형 그래프(relational graph)** 로 관리하는 데스크톱 애플리케이션.
링크를 저장하고 태그를 부여하며, 링크 간 의미적 관계를 생성한다. 관계는 인터랙티브 그래프로 시각화·탐색된다.

## 3. 핵심 가치 (왜 폴더형 북마크보다 나은가)

| 기존 북마크 (트리) | LinkMap (그래프) |
|---|---|
| 하나의 링크는 하나의 폴더에만 속함 | 하나의 링크가 여러 태그·여러 링크와 동시에 연결 |
| 관계 표현 불가 | `related` / `uses` / `part_of` 등 의미적 엣지 |
| 맥락 손실 | 노드를 따라 지식 맥락을 탐색 |

```
폴더형                LinkMap (그래프)
Folder                AI ── OpenAI ── ChatGPT
 └ OpenAI                 │      └ GPT-4
 └ ChatGPT                └ Claude   └ OpenAI API
```

## 4. 타깃 사용자
- 리서처 / 개발자 / 지식 노동자 — 링크를 많이 모으지만 폴더로는 맥락을 잃는 사람.
- 단일 사용자, 로컬 우선(local-first). v1은 동기화·계정 없음.

## 5. MVP 범위 (In Scope)
사용자는 다음을 수행할 수 있어야 한다:
1. **링크 저장** — 수동 폼 입력 + URL 드래그앤드롭, OpenGraph 메타데이터 자동 수집.
2. **태그 관리** — 태그 생성·색상 지정·링크에 부여(N:M).
3. **관계 생성** — 두 노드 사이에 타입이 있는 엣지 생성.
4. **그래프 탐색** — Force-directed 그래프에서 검색·필터·줌·미니맵으로 탐색.
5. **상세 관리** — 우측 패널에서 상세정보·관계·메모(Markdown)·미리보기 확인/편집.

## 6. 범위 외 (Out of Scope — v1)
- 클라우드 동기화 / 멀티 디바이스 / 계정·인증
- 협업 / 공유 / 실시간
- 브라우저 익스텐션 (drag&drop으로 대체)
- AI 자동 관계 추천 (v2 후보)
- Hierarchical / Radial 레이아웃은 **선택 구현** (Force-directed가 필수, 나머지는 stretch)

## 7. 핵심 사용자 흐름
1. **수집**: URL 드롭 → 메타 자동 수집 → 노드 생성 → 태그 부여.
2. **연결**: 노드 A 우클릭 → Create Relation → 노드 B 선택 → 타입 지정.
3. **탐색**: 검색(`tag:AI`) → 결과 하이라이트 → 노드 클릭 → 우측 상세 동기화 → 더블클릭으로 원문 열기.

## 8. 성공 기준 (MVP Done)
- [ ] 링크 CRUD + 메타 자동수집 동작
- [ ] 태그 CRUD + N:M 부여
- [ ] 관계 CRUD (6개 타입) 동작
- [ ] React Flow Force-directed 그래프에 링크/태그/컬렉션 노드 렌더 + 엣지 스타일 구분
- [ ] 검색/필터/줌/미니맵 동작
- [ ] 우측 4탭(상세/관계/메모/미리보기) 동작
- [ ] SQLite에 영속화, 앱 재시작 후 상태 유지
- [ ] 시드 데이터로 첫 실행 시 데모 그래프 표시
- [ ] `npm run dev` 한 번으로 실행 가능한 런어블 MVP

## 9. 비기능 요구
- **로컬 우선**: 모든 데이터 SQLite 로컬 파일. 외부 네트워크는 메타 수집 시에만.
- **성능**: 노드 200개까지 60fps 목표(force 시뮬레이션 시 점진 안정화).
- **유지보수성**: feature-based 폴더 구조, 타입 안전(TS strict).
